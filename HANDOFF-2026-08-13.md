## Decisions made this session that aren't fully reflected in code comments elsewhere

- **Audio simulation is permanently non-user-facing.** Joe: *"as for the audio one, i dont
  see a point in it at all except maybe for testing."* `runAudioSimulationEngine()` is
  reachable only via the debug-gated `AdbControlReceiver`'s `start_simulation` command.
  Do not add any UI path to it.
- **Demo mode (simulated BLE) is a real, wanted feature**, explicitly *not* under
  Settings > Experimental — Joe asked for it in the main Settings list. It's there now
  ("Demo Mode" card).
- **The connect/error UI direction was Joe's, not a suggestion I made.** He asked for "an
  expressive large shape morphing animation in the middle of the screen" and one unified
  surface instead of a pill (top) + snackbar (bottom) that could show contradictory things
  simultaneously. That's `ui/components/ConnectionStatusSurface.kt` now.
- **The hunting indicator has no Cancel button any more.** It's bare — no card, no
  caption, no button, 200dp, fully non-interactive so touches pass through to the tab
  underneath — because Joe's ask was for something big and standalone. The 15-second
  timeout is now the *only* thing that dismisses it. I flagged this tradeoff to Joe but
  he hasn't explicitly signed off on "no way to cancel a hunt early" as acceptable — if he
  complains about this, the fix is adding some minimal touch target back, not reverting to
  a card.
- **A real mistake, corrected within the session:** I first told Joe material3 didn't ship
  `LoadingIndicator` in any version and hand-rolled a shape-morph with
  `androidx.graphics:graphics-shapes`. Joe pushed back ("we created the animation
  ourselves?"), which was the right call — I'd only probed the version numbers `1.4.1`
  and `1.5.0`, neither of which exists as a published artifact, and wrongly read that as
  "nothing newer is available." Requesting `version = "+"` (or trying an alpha directly)
  found `1.5.0-alpha25`, which has the real components. The hand-rolled version and its
  dependency are deleted; `material3` is now pinned to `1.5.0-alpha25` explicitly past the
  BOM. See `CLAUDE.md`'s new "Material 3 Expressive" section and `IMPROVEMENT_PLAN.md`'s
  "UI direction change" section for the full mechanics (the `compileSdk` 37 forcing, why
  `targetSdk` stayed at 36, where the pin lives).
